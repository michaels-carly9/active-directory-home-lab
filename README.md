# active-directory-home-lab
Overview: Built an Active Directory home lab using Windows Server, DNS, Active Directory Domain Services, Organizational Units, Security Groups, domain-joined clients, and file share permissions.

The purpose of this lab was to gain hands-on experience with Windows Server administration, identity management, access control, and troubleshooting in a simulated enterprise environment.

Skills Demonstrated 
 - Windows Server 2022 Administration
 - Active Directory Domain Services (AD DS)
 - DNS Configuration and Management
 - Organizational Unit (OU) Design
 - Security Group Management
 - User Account Administration
 - Computer Account Management
 - Domain Joining Windows Clients
 - NTFS Permissions
 - Shared Folder Permissions
 - Documentation and Change Management. 

 Lab Environment
 Hypervisor - VirtualBox

 Server
    Windows Server 2022
    Domain Controller
    DNS Server

Clients
    Windows 11 Pro Domain-Joined Workstations
